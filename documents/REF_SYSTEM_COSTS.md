# 名刺代わりに - 運営・インフラ費用（ランニングコスト）ガイド

本プロジェクト「名刺代わりに」は、AWSを用いた**サーバーレスアーキテクチャ**を採用しています。
一般的なレンタルサーバー（月額固定費）とは異なり、基本的には**「使った分だけ支払う（従量課金制）」**ため、アクセスが少ない初期段階では非常に安価（もしくは無料枠内）で運用できるのが特徴です。

このドキュメントでは、本サービスを運営する上で「どのサービスに」「どのくらいの費用が」かかるのかをまとめました。

---

## 1. 固定費（必ず発生する費用）

アクセス数に関わらず、独自のブランド名（URL）を維持するために固定の費用が発生します。

### 🌐 Amazon Route 53 (ドメイン・DNS管理)
* **ドメイン更新費用 (年額)**: **約 $15 / 年**
  * 本サービスのために独自ドメインを契約・維持するための費用です。年に1回請求されます。
* **ホストゾーン維持費用 (月額)**: **$0.50 / 月**
  * ドメインとシステムを紐づけるためのDNS設定（ホストゾーン）を維持する費用です。
* **DNSクエリ**: $0.40 / 100万クエリ
  * ※アクセス数が膨大にならない限り、ほぼ無視できる金額です。

---

## 2. 従量課金（アクセス数・データ量に応じて変動する費用）

以下のAWSサービスは、システムの利用状況（フロントエンドの表示、APIの呼び出し、画像の保存など）に応じて課金されます。**ただし、AWSには毎月使える「無料利用枠」が豊富に用意されているため、サービスが小規模なうちは以下の大部分が無料枠に収まる可能性が高いです。**

### 💻 AWS Amplify (フロントエンドのホスティング)
ユーザーが画面（Next.js）を閲覧する際の通信データや、ソースコードのデプロイ（ビルド）にかかる費用です。
* **ビルド費用**: $0.01 / 1ビルド分(時間)
* **データ保存**: $0.023 / GB・月
* **データ転送（アウト）**: $0.15 / GB
* *(※無料枠: 毎月1000ビルド分、5GBの保存、15GBのデータ転送まで無料)*

### 🚪 Amazon API Gateway (API通信の窓口)
フロントエンドからバックエンド（Lambda）へリクエストを送る際の窓口となるサービスです。
* **リクエスト料金**: $4.25 / 100万リクエスト
* *(※無料枠: 初めの12ヶ月間、毎月100萬リクエストまで無料)*

### ⚙️ AWS Lambda (プログラムの実行)
商品の登録やQRコードの発行など、裏側でプログラムが動いた「時間」と「回数」に対して課金されます。
* **リクエスト料金**: $0.20 / 100万リクエスト
* **コンピューティング料金**: メモリ割り当て量と実行時間 (ミリ秒) に応じて課金
* *(※無料枠: 永久に毎月100万リクエスト、および40万GB秒まで無料。通常のアクセス量であればほぼ課金されません)*

### 🗄️ Amazon DynamoDB (データベース)
ショップ情報、商品情報、QRコードなどを保存し、読み書きする費用です。オンデマンドキャパシティモードを想定しています。
* **書き込み**: $1.25 / 100万書き込み単位
* **読み込み**: $0.25 / 100万読み込み単位
* **ストレージ保存**: $0.25 / GB・月
* *(※無料枠: 永久に25GBの保存と、一定の読み書きキャパシティが無料)*

### 📦 Amazon S3 (ファイル・画像ストレージ)
ユーザーがアップロードした「商品画像」などを保存するためのストレージです。
* **データ保存**: $0.025 / GB・月
* **リクエスト料金（書き込み/読み込み）**: 数ドル / 1万リクエストあたり
* *(※無料枠: 初めの12ヶ月間、5GBの保存と特定の回数の読み書きが無料)*

### 🔐 Amazon Cognito (ユーザー認証)
管理者やショップオーナーがログインするための機能です。
* **料金**: 月間アクティブユーザー (MAU) に応じて課金
* *(※無料枠: 永久に毎月50,000 MAUまで無料。大規模なサービスにならない限り無料です)*

---

## 3. 外部サービス（AWS以外）

### ✉️ Resend (システムメール送信)
注文通知やギフトの受け取り案内などをメールで送信するために使用しています。
* **無料プラン**: 毎月3,000通 (1日100通) まで無料
* **有料プラン (Pro)**: 月額 $20 (毎月50,000通から)
  * 仮にサービスが成長し、1日100通を超えるシステムメールを送るようになった場合は、有料プランへのアップグレードが必要になります。

---

## 💰 費用目安のまとめ

**立ち上げ時・小規模運営時（アクセスが少ない場合）**
* ドメイン更新料（年額 $15）と、DNSホストゾーン維持料（月額 $0.50）の**ほぼ固定費のみ**で運営可能です。（月額数百円レベル）
* 多くのサービスが無料枠に収まります。

**中〜大規模運営時（アクセスが増えた場合）**
* S3の画像ストレージやAmplifyの通信量が増え始めると、数百円〜数千円と徐々に課金が発生します。
* 注文が頻繁に入り、メール送信が1日100通を超える場合は、Resendの有料プラン（月額$20）が発生します。

## 💡 予期せぬ高額請求を防ぐために
悪意のある大量アクセス（DDoS攻撃など）や設定ミスによって、従量課金が数万円規模に跳ね上がるリスクがゼロではありません。これを防ぐために、**AWSの「AWS Budgets（予算）」機能や「CloudWatch アラーム」機能を使って、「月の費用が$10を超えたら管理者にメール通知する」といったアラート設定を必ず行っておくことを強くお勧めします。**

## 予算原資
* ドメイン使用料以外は アカウント作成時の$100の無料枠を使用しているため、ほぼ無料で運用できています。
