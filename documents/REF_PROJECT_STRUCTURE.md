# [名刺がわりに] プロジェクト構成リファレンス (Project Structure Reference)

本プロジェクトのディレクトリ構成と、それぞれの役割についての解説です。開発時のファイルの配置場所や、目的のファイルを探す際の参考にしてください。

---

## 📂 全体構造 (Root Directory)

プロジェクトのルートディレクトリには、環境設定、全体ドキュメント、および各主要モジュール（フロントエンド、インフラ、共有コード）が配置されています。

| ディレクトリ / ファイル | 役割 |
| :--- | :--- |
| `frontend/` | Next.js を使用したフロントエンド・アプリケーション。 |
| `infra/` | AWS CDK を使用したインフラ定義と、Lambda 関数（バックエンド）。 |
| `shared/` | フロントエンドとバックエンドで共有される定数や型定義。 |
| `documents/` | システム仕様書、構築手順、リファレンスなどのドキュメント群。 |
| `README.md` | プロジェクトの概要とクイックスタートガイド。 |
| `TODO.md` | 現在進行中のタスクや将来の改善予定リスト。 |
| `amplify.yml` | AWS Amplify ホスティングのビルド設定ファイル。 |

---

## 🎨 デザイン・アセット関連 (Japanese Folders)

主にデザイン案、画像素材、ビジネス資料などが日本語名のフォルダに格納されています。

| フォルダ名 | 内容 |
| :--- | :--- |
| `カードデザイン/` | 名刺カードのデザイン案（PPTX, PNG, PDF）や画像素材。 |
| `カード生成情報/` | カード生成に関連する設定やデータ。 |
| `書類/` | ユーザー向けガイドなどのドキュメント類。 |
| `紹介ページデザイン例/` | ランディングページや紹介画面のデザインサンプル・プロンプト。 |
| `送り主情報例/` | 送り主情報のサンプルデータ。 |

---

## 🌐 フロントエンド (`frontend/`)

Next.js (App Router) をベースとした構成です。

| ディレクトリ / ファイル | 役割 |
| :--- | :--- |
| `app/` | ルーティングと各ページのロジック。 |
| `components/` | 再利用可能な UI コンポーネント（Shadcn/ui など）。 |
| `context/` | ShopContext などの React Context 定義。 |
| `lib/` | API クライアント、ユーティリティ関数。 |
| `store/` | 状態管理に関連する定義。 |
| `public/` | 画像、アイコン、フォントなどの静的ファイル。 |
| `messages/` / `i18n/` | 表示文言メッセージとロケール関連設定（運用方針は [SPEC_HOW_TO_DEVELOP_FRONTEND.md](./SPEC_HOW_TO_DEVELOP_FRONTEND.md) を参照）。 |
| `package.json` | フロントエンドの依存ライブラリ管理。 |

---

## ☁️ インフラ・バックエンド (`infra/`)

AWS CDK (v2) を使用したサーバーレスアーキテクチャの定義です。

| ディレクトリ / ファイル | 役割 |
| :--- | :--- |
| `bin/` | CDK アプリケーションのエントリポイント。 |
| `lib/` | AWS リソース（API GW, DynamoDB, S3, Cognito 等）の定義。 |
| `lambda/` | バックエンドの実際のロジック（TypeScript）。 |
| 　├ `authorizer/` | API Gateway の認可ロジック。 |
| 　└ `utils/` | Lambda 間共通のユーティリティ。 |
| `scripts/` | デプロイやデータ操作用の補助スクリプト。 |
| `cdk.json` | CDK の構成設定（コンテキスト、機能フラグ等）。 |

---

## 🔗 共有コード (`shared/`)

フロント・バック両方で参照されるソースコードです。

| ファイル | 役割 |
| :--- | :--- |
| `api-types.ts` | API のリクエスト/レスポンス、DB モデルの型定義。 |
| `constants.ts` | CORS 設定や環境固有の値などの共通定数。 |

---

## 📖 ドキュメント (`documents/`)

このプロジェクトの「仕様」や「ルール」をまとめた場所です。

- **ATFIRST_**: 初期導入ガイド。
- **SETUP_**: 構築・運用の手順書。
- **SPEC_**: 技術的な詳細仕様。
- **REF_**: 一覧表などのリファレンスデータ。
- **INDEX.md**: すべてのドキュメントのポータルページ。
