# 開発環境おまかせセットアップガイド（完全初心者向け）

このガイドは、**「これまでプログラミングや開発環境の構築を全くやったことがない」**という方を対象に、MeishiGawariniプロジェクトに参加するための手元のPC（ローカル環境）の準備手順をゼロから解説します。

順番通りに進めれば必ず動くようになりますので、一つずつ確認しながら進めていきましょう！

---

## ステップ 0: AWS アカウントの基本構造（親子関係）

本プロジェクトでは、1つの **AWSメインアカウント** を共有し、その中に開発者ごとの **IAMユーザー** を作成して運用します。

* **メインアカウント (親)**: 
    * 支払い（請求）が一括管理される場所。
    * DynamoDB, S3, Cognito などの実リソースが存在する場所。
* **IAMユーザー (子)**: 
    * 開発者個人のログインID。
    * 「誰がどの操作をしたか」を識別するために、開発者ごとに作成します。
    * **重要**: 開発者自身が個別に「新しいAWSアカウント」を新規作成する必要はありません。

## ステップ 1: 必要なソフトウェア（ツール）をインストールする

開発にはいくつかの専用のソフトウェアが必要です。以下の4つを順番にインストールしてください。
すでにインストール済みのものがある場合は、そのステップは飛ばして構いません。

### 1-1. Visual Studio Code (VS Code) のインストール
プログラミングのコードを書いたり読んだりするための、世界で一番使われているエディタです。
*   **ダウンロード先**: [https://azure.microsoft.com/ja-jp/products/visual-studio-code/](https://azure.microsoft.com/ja-jp/products/visual-studio-code/)
*   **手順**: 自分のPC（Windows または Mac）に合った青いダウンロードボタンを押し、ダウンロードされたファイルを開いて、画面の指示に従ってインストール（「次へ」を押し続けるだけでOK）してください。

### 1-2. Git (ギット) のインストール
コードの履歴やバージョンを管理するためのツールです。
*   **Windowsの方**: [https://gitforwindows.org/](https://gitforwindows.org/) からダウンロードし、実行してインストールします（設定はすべて「次へ」で大丈夫です）。
*   **Macの方**: 最初からインストールされていることが多いですが、念のためターミナル（後述）を開いて `git --version` と入力し、バージョンが表示されればOKです。表示されない場合は、画面の指示に従ってAppleのツールをインストールしてください。

### 1-3. Node.js (ノード・ジェイエス) のインストール
これが無いと今回のシステム（フロントエンドもバックエンドも）は動きません。JavaScriptを動かすためのエンジンです。
*   **ダウンロード先**: [https://nodejs.org/ja](https://nodejs.org/ja)
*   **手順**: 画面に大きく表示されている **「LTS (推奨版)」** のボタン（2024年現在は **`22.x.x LTS`** 以上を推奨）をクリックしてダウンロードし、インストールしてください。

### 1-4. AWS CLI のインストール
*   **ダウンロード先と手順**: [AWS公式のインストール手順（日本語）](https://docs.aws.amazon.com/ja_jp/cli/latest/userguide/getting-started-install.html)
    *   Windows: 公式ページから `.msi` ファイルをダウンロードして実行します。
    *   Mac: 公式ページの Mac 用 `pkg` ファイルをダウンロードして実行します。

### 1-5. AWS CLI の認証 (SSO ログイン)
インストールした AWS CLI を使って、本プロジェクトの AWS 環境にログインできるようにします。

1.  管理者（または招待メール）から共有された **「AWS アクセスポータル URL（スタートURL）」** を手元に用意します。
2.  ターミナル（次のステップで開き方を説明します）で以下のコマンドを実行します。
    ```bash
    aws configure sso
    ```
3.  画面の指示に従ってスタートURLとリージョン（`ap-northeast-1`）を入力し、ブラウザが開いたらログインを完了させてください。
4.  一度設定が完了すれば、次からは以下のコマンドだけでログインできます。
    ```bash
    aws login
    ```

## ステップ 2: ターミナル（黒い画面）を開く

ここからの作業は、**VS Code内蔵の「ターミナル（Terminal）」**（コマンドを打ち込んでコンピュータに指示を出す画面）を使って行います。

1.  インストールした **VS Code** を開きます。
2.  画面上部のメニューから **「ターミナル (Terminal)」** > **「新しいターミナル (New Terminal)」** をクリックします。
3.  画面の下半分に黒い（またはターミナル風の）領域が表示されます。ここに文字を打ち込んでエンターキーを押すと、コマンドが実行されます。

---

## ステップ 3: プロジェクトのコードを自分のPCに持ってくる

GitHub（コードが置いてあるインターネット上の倉庫）から、作業用のコードを手元にコピーします。

1.  VS Codeの下に開いたターミナルに、以下の文字をコピー＆ペーストして**「Enter」**キーを押してください。

```bash
git clone https://github.com/yudaiito9124-cyber/meishigawarini.git
```
※もしパスワードなどを聞かれた場合は、GitHubのアカウント情報を入力してください。

2.  ダウンロードが完了したら、ターミナルで以下のコマンドを入力して対象のフォルダに移動します。

```bash
cd meishigawarini
```
*(`cd` は Change Directory の略で、フォルダを移動するという意味です)*

3.  VS Codeのメニュー「ファイル」 > 「フォルダーを開く（Open Folder）」から、今ダウンロードした `meishigawarini` フォルダを選択して開いてください。

## ステップ 4: 必要なプログラム部品をダウンロードする

システムを動かすためには、他人が作った便利なプログラムの部品（パッケージと呼びます）を大量にダウンロードしてくる必要があります。
（※これはプロジェクトに初めて参加した時だけ行う作業です）

新しいターミナルを再度開き（VS Codeのメニューから「ターミナル」 > 「新しいターミナル」）、以下のコマンドを**順番に一つずつ実行**（コピーしてEnter）してください。

### 1. フロントエンド（画面）側の準備
```bash
# フロントエンドのフォルダに移動
cd frontend

# フロントエンド用の部品をまとめてダウンロード
npm install
```
*(※この処理は数分かかることがあります。文字がたくさん流れますが、止まるまで待ってください)*

### 2. インフラ（裏側の処理）の準備
先ほどの処理が終わったら、続いて以下を実行します。

```bash
# 一つ上のフォルダに戻ってから、インフラのフォルダに移動
cd ../infra

# インフラ用の部品をまとめてダウンロード
npm install
```

## ステップ 5: 環境変数（秘密のパスワードなど）を設定する

アプリを動かすための「秘密のURL」や「パスワード」のようなものを設定します。これらは絶対にインターネット上に公開してはいけないため、手動でファイルを作って管理します。

このプロジェクトには複数の環境変数ファイルがあります。それぞれの役割を理解しましょう。

### 5-1. 環境変数ファイルの種類と役割

#### フロントエンド (`frontend/` フォルダ内)
| ファイル名 | 役割 | 備考 |
| :--- | :--- | :--- |
| **`.env.local`** | **[最重要]** ローカル実行時に実際に読み込まれるファイル | Git管理外。ここに設定を書きます。 |
| `.env.staging` | 検証環境（Staging）用のテンプレート | `npm run dev:stg` を実行すると `.env.local` にコピーされます。 |
| `.env.production` | 本番環境（Production）用のテンプレート | `npm run dev:prod` を実行すると `.env.local` にコピーされます。 |

#### インフラ (`infra/` フォルダ内)
| ファイル名 | 役割 | 備考 |
| :--- | :--- | :--- |
| `.env.stg` | 検証用AWSへのデプロイ時に使用 | Git管理外。検証用APIキーなどを記載。 |
| `.env.prod` | 本番用AWSへのデプロイ時に使用 | Git管理外。本番用APIキーなどを記載。 |

> [!WARNING]
> **`.env.local` の上書きに注意！**
> `npm run dev:stg` や `npm run dev:prod` を実行すると、現在の `.env.local` は `.env.staging` または `.env.production` の内容で**完全に上書き**されます。
> 特定の環境で設定を固定したい場合は、`.env.staging` などのソースファイルを編集するか、実行後に `.env.local` を再調整してください。

### 5-2. 初期設定の手順

1. VS Codeで `frontend` フォルダ内に **`.env.local`** ファイルを作成します。
2. チームの管理者から指定された「検証環境（Staging）用の設定値」をコピーして貼り付けます。
3. 同様に、必要に応じて `infra` フォルダ内に **`.env.stg`** を作成し、指定された値を貼り付けます。

*(※各ファイルの具体的な値については、セキュリティ保護のため Slack や専用のドキュメントで別途共有されます)*

## ステップ 6: 自分のPCでアプリの画面を動かしてみる！

すべての準備が完了しました！最後に、正しく画面が表示されるか確認しましょう。

1. ターミナルで以下のコマンドを実行します。
```bash
# プロジェクトのルート（一番上の階層）にいることを確認して実行
cd frontend

# アプリの起動コマンド！
npm run dev
```

> [!TIP]
> **検証環境（Staging）のデータで動かしたい場合**は、以下のコマンドを使います（推奨）。
> ```bash
> npm run dev:stg
> ```

2. ターミナルに緑色の文字などで `Ready in xxx ms` や `Local: http://localhost:3000` と表示されたら大成功です！
3. ブラウザ（Chromeなど）を開き、上のアドレスバーに **`http://localhost:3000`** と入力して開いてみてください。
4. アプリの画面が表示されれば、**開発環境の構築は完了**です！お疲れ様でした！

*(※ 開発を終了したい時は、ターミナルの画面をクリックして `Ctrl + C`（Macは `Control + C`）を押し、`Y` を押してエンターを押せばサーバーが停止します)*

## ステップ 7: AI アシスタントのセットアップ (オプション)

このプロジェクトでは、AI（Antigravity や Cursor 等）を活用した開発を強力に推進しています。ただし、AI がプロジェクト固有のルールを無視してコードを破壊しないよう、**AI 用の「しつけ（命令ファイル）」**を読み込ませる必要があります。

### 7-1. プロジェクト固有スキルの認識
リポジトリ内の以下のファイルに、AI が守るべき「鉄則」が記載されています。
- **[.agent/skills/development/SKILL.md](../.agent/skills/development/SKILL.md)**

新しい AI アシスタントを使い始める際は、まずこのファイルの中身を AI に読み込ませ、「このルールに絶対に従って開発してください」と指示してください。

### 7-2. なぜ初期設定で行うべきなのか？
AI はデフォルトの状態では一般的なコードしか書けません。最初にこのセットアップを行わないと、以下のような問題が発生します：
- 複雑なデータベース（DynamoDB）のキー構造を無視したクエリを書く。
- 既存の便利な共通関数を無視して、同じようなコードを新しく作ってしまう。
- ドキュメントを勝手に書き換えて情報をロストさせる。

**「AI とペアプロを始める前に、まず SKILL.md を読ませる」** ことを、環境構築の最後のステップとして強く推奨します。

## ステップ 8: （管理者向け）新規開発者を招待する手順

新しいメンバーがプロジェクトに参加する場合、**管理者（オーナー）**が以下の作業を行う必要があります。

### 1. 必要な情報の共有・招待
管理者は新規メンバーに対して以下を用意し、Slack等の安全なツールで渡してください。
1.  **GitHubリポジトリの招待**: [yudaiito9124-cyber/meishigawarini](https://github.com/yudaiito9124-cyber/meishigawarini) への招待。
2.  **AWS IAMユーザーの発行**: (後述) 発行された `ログインURL` `ユーザー名` `初期パスワード`。
3.  **アプリ管理者アカウントの作成指示**: アプリ画面から「メールアドレスとパスワード」でサインアップするよう伝えてください。
    *   > [!IMPORTANT]
    *   > **外部認証（Google/Apple等）は使用禁止**です。外部認証ではMFAが有効化されないため、管理画面へのアクセスができません。
4.  **環境変数 (`.env.local` / `.env`)**: API URLなどの動作に必要な設定値。
5.  *(任意)* **Resend (メール送信) のテスト用APIキー**

### 2. AWS 認証環境の発行手順
本プロジェクトでは **AWS IAM Identity Center (旧SSO)** を利用しています。

1.  AWS 管理コンソールで IAM Identity Center を開き、新規ユーザーを作成します。
2.  作成したユーザーを適切な権限グループ（`AdministratorAccess` 相当など）に割り当てます。
3.  **「AWS アクセスポータル URL」「ユーザー名」「初期パスワード」** をメンバーに共有してください。
