## ▌ このプロンプトの使い方

このプロンプトは、WebサイトのURLや提供情報をもとに、
任意のページへ埋め込める「自己完結型HTMLウィジェット」を
生成AIに生成させるための指示書です。

### 基本的な使い方

1. 「SECTION 1：共通入力パラメータ」を必ず埋める
2. 主体・目的に応じて「SECTION 2：用途別追加パラメータ」の
   該当ブロック（A/B/C）も埋める
3. このファイル全体をそのまま生成AIに貼り付けて使う
4. URLがない場合は「なし」と記入し、情報を直接テキストで記述する

### 対応している用途

  A. 個人向け
     A1 ポートフォリオ・技術者自己紹介
     A2 プロフィールカード（SNS・名刺代わり）
     A3 プライベート・人生の節目（慶事／転機／弔事）

  B. ビジネス向け（BtoB）
     B1 会社紹介・コーポレートブランディング
     B2 営業担当者・ビジネス自己紹介
     B3 BtoB商品・サービス紹介
     B4 採用告知・採用ブランディング
     B5 実績・導入事例紹介

  C. 消費者向け（BtoC）
     C1 ブランディング・世界観紹介
     C2 商品紹介（一般消費者向け）
     C3 キャンペーン・セール・期間限定告知
     C4 店舗・サービス案内

  D. 公共・公的機関向け
     D1 官公庁・行政機関
     D2 教育機関（大学・学校）
     D3 NPO・非営利団体・社会活動
     D4 医療・福祉・介護機関

  E. イベント・プロジェクト向け
     E1 ビジネスイベント（セミナー・展示会・カンファレンス）
     E2 一般向けイベント（コンサート・フェス・スポーツ）
     E3 クラウドファンディング・プロジェクト支援

## ▌ STEP 1：情報収集・自動判定

URLが指定されている場合は対象URLにアクセスし、
SECTION 1〜2で「自動判定」とされた項目をサイトから推定してください。

推定した場合は生成HTMLの冒頭コメントに以下を記載してください：

```html
<!--
  [自動判定結果]
  主体   → ○○
  目的   → ○○
  トーン → ○○
  適用パターン → ○○
-->
```

URLがない場合（「なし」と記入された場合）は、
SECTION 2に記入された情報のみをもとにHTMLを生成してください。

## ▌ STEP 3：HTMLの生成

以上のSTEP 1・2をもとに、以下の共通仕様でHTMLを生成してください。

---

### 共通技術仕様（全パターン必須）

#### 1. スコープ限定CSS

全CSSクラスにユニークなプレフィックスを付ける。
例：`.widget-teian-root`、`.life-memorial-root`、`.biz-corp-root`

```css
/* 必ずこの形式で始める */
.{prefix}-root,
.{prefix}-root * {
    box-sizing: border-box !important;
    margin: 0;
    padding: 0;
}
```

#### 2. 出力形式

- `<style>〜</style>` と `<div>〜</div>` ブロックのみ出力
- `<html>`・`<head>`・`<body>` タグは出力しない（自動で付与されるため）
- 外部フォントの `<link>` タグは出力してよい

#### 3. 幅・レイアウト

- ラッパーの最大幅は `max-width: 560px`（BtoB系は `max-width: 640px` まで可）
- 中央寄せ: `margin: 0 auto`
- モバイル対応: `width: 100%` を基本とし、`max-width` で上限を設定

---

### ⚠️ iframeサンドボックス必須制約（絶対に守ること）

このHTMLはSandboxedHtml.tsxのiframe内で動作します。
以下のルールを1つでも破るとレイアウトが壊れます。

#### ❌ 使用禁止のCSS

```css
/* 以下はすべて絶対に使用禁止 */

height: 100vh;          /* iframeがビューポート全体を報告し無限ループになる */
min-height: 100vh;      /* 同上 */
height: 100%;           /* ラッパー要素での使用は禁止（親がautoなので0になる） */
min-height: 100%;       /* 同上 */
position: fixed;        /* iframe内では意味をなさず崩れる */

/* vhユニット全般（vw・vmin・vmaxも原則禁止） */
height: 50vh;           /* 禁止 */
padding: 5vh 0;         /* 禁止 */
```

#### ✅ 正しい高さの指定方法

```css
/* 方法1：固定px値（コンテンツ量が予測できる場合） */
.panel {
    height: 1200px; /* コンテンツに合わせた固定値 */
}

/* 方法2：height: auto（コンテンツ量が可変の場合・推奨） */
.wrapper {
    height: auto;   /* コンテンツの高さに自動追従 */
    padding: 40px 20px; /* paddingで上下の余白を確保 */
}

/* 方法3：動画・地図のアスペクト比維持 */
.video-wrap {
    position: relative;
    padding-top: 56.25%; /* 16:9のアスペクト比 */
    height: 0;
    overflow: hidden;
}
.video-wrap iframe {
    position: absolute;
    top: 0; left: 0;
    width: 100%; height: 100%;
    border: none;
}
```

#### ✅ 使用可能な外部リソース（CSPで許可済み）

| リソース種別 | 使用可能なもの |
|---|---|
| フォント（CSS） | https://fonts.googleapis.com |
| フォント（ファイル） | https://fonts.gstatic.com（自動） |
| CDN（JS/CSS） | https://cdnjs.cloudflare.com |
| CDN（JS/CSS） | https://cdn.jsdelivr.net |
| CDN（JS/CSS） | https://unpkg.com |
| CSSフレームワーク | https://cdn.tailwindcss.com |
| iframe埋め込み | https://www.youtube.com（YouTube） |
| iframe埋め込み | https://www.youtube-nocookie.com |
| iframe埋め込み | https://www.google.com/maps（Google Maps） |
| 画像 | https: 全般（外部画像URLは直接使用可） |

#### ❌ 使用できないもの

```
- 上記以外の外部スクリプト
- YouTube・Google Maps以外のiframe（sandboxがallow-scriptsのみに制限される）
- localStorage / sessionStorage（sandboxの制限により動作しない場合がある）
- alert() / confirm() 等のダイアログ（sandbox制限）
```

#### ❌ JavaScript（<script>タグ）は使用禁止

⚠️ DOMPurify.sanitize() の ADD_TAGS に "script" が含まれていないため、
   ユーザーHTMLに含まれる <script> タグはすべてサニタイズ時に除去されます。
   CSPで 'unsafe-inline' が許可されていても、タグ自体が消えるため意味がありません。

   以下はすべて動作しません：
   - <script> タグ（inline・外部CDN問わず）
   - カウントダウンタイマー（setInterval）
   - クリックイベント（addEventListener）
   - DOM操作（document.getElementById など）
   - アコーディオン開閉（classList.toggle など）

#### ✅ 動的表現はCSSのみで実現する

| やりたいこと | JavaScript版（❌ 使えない） | CSS代替（✅ 使える） |
|---|---|---|
| ホバーエフェクト | addEventListener | :hover + transition |
| ボーダーアニメーション | JS不要 | @keyframes + conic-gradient |
| フェードイン | JS不要 | @keyframes fadein + animation |
| プログレスバー | JS不要 | width: 60% を直接CSSに書く |
| アコーディオン | classList.toggle | <details><summary>タグ（HTML標準） |
| カウントダウン | setInterval | 生成AIが計算した数値を静的テキストとして埋め込む |
| スライドショー | JS切り替え | CSS animationで自動切り替え（高さ固定必須） |

## ▌ 付録 B：よくあるミスと対処法

### ミス 1：min-height: 100vh を wrapper に使ってしまう

```css
/* ❌ NG */
.wrapper {
    min-height: 100vh;
}

/* ✅ 修正後 */
.wrapper {
    height: auto;
    padding: 40px 20px; /* paddingで上下の余白を確保 */
}
```

---

### ミス 2：カード固定高さが不足してコンテンツが切れる

```css
/* ❌ NG：コンテンツが溢れる */
.card {
    height: 600px;
    overflow: hidden;
}

/* ✅ 修正後：コンテンツに応じた高さ */
.card {
    height: auto;
    min-height: 600px; /* 最低高さは保証しつつ、超えても大丈夫 */
}
```

---

### ミス 3：動画をpaddingトリックなしでiframeに埋め込む

```html
<!-- ❌ NG：iframeに固定heightを直接指定 -->
<iframe src="..." width="100%" height="315"></iframe>

<!-- ✅ 修正後：paddingトリックでアスペクト比維持 -->
<div style="position:relative; padding-top:56.25%; height:0;">
    <iframe src="..."
        style="position:absolute;top:0;left:0;width:100%;height:100%;border:none;">
    </iframe>
</div>
```

---

### ミス 4：弔事系なのに明るいデザインにしてしまう

弔事・追悼系のパターンでは以下を厳守：
- 背景色は白（#ffffff）のみ
- テキストカラーはグレー系（#333〜#888）
- アクセントは薄いグレーか淡い紺のみ
- アニメーション・グラデーション・鮮やかな色は一切禁止
- CTAボタンは枠線型のみ（塗りつぶし禁止）

---
