# システム管理者マニュアル（ツール）

システム管理の補助機能である「データダンプ」ツールの使い方を説明します。主にエンジニアや高度な管理権限を持つユーザーが、データベース（DynamoDB）の生データを確認するために使用します。

## 1. データダンプ機能の概要

各エンティティのID（ユーザーID、ショップIDなど）を指定して、データベースに保存されている情報をJSON形式で取得します。
- **GSI 2対応**: `PRODUCT#` や `CARD_ORDER#` など、特定のインデックス（GSI 2）を介した検索が必要なデータにも対応しています。

## 2. 検索可能なデータ種別

ツール画面には、以下の種別ごとの検索カードが用意されています。

- **ユーザー (USER#)**: アカウントの詳細情報。
- **ショップ (SHOP#)**: ショップの基本設定。
- **商品 (PRODUCT#)**: ショップに紐づく商品データ（GSI 2経由）。
- **QR (QR#)**: 個別のカードデータ。
- **カード印刷 (CARD_ORDER#)**: 発注データの詳細（GSI 2経由）。
- **QRバッチ (QR_BATCH#)**: 一括生成バッチのメタデータ、発行済みID一覧。
- **カードデザイン (CARD_DESIGN#)**: 作成・登録されたデザイン定義。

## 3. 操作手順

1.  **IDの入力**: 検索したいデータのID（数字部分など）を入力します。プレフィックス（`USER#`等）は自動的に付与されます。
2.  **実行**: 「実行」ボタン（虫眼鏡アイコン）をクリックします。
3.  **結果の確認**: 取得に成功すると、画面上にJSON形式で生データが表示されます。「Hide」ボタンで結果を閉じることができます。
4.  **クリア**: ゴミ箱アイコンを押すと、入力内容と検索結果がリセットされます。
