# ツール

[管理者ダッシュボード](/admin) の「ツール」タブにおける、システム管理の補助機能である「データダンプ」ツールの使い方を説明します。主にエンジニアや高度な管理権限を持つユーザーが、データベース（DynamoDB）の生データを確認するために使用します。
![ツール](/images/manual/admin++TAB=tools.webp)

※IDの確認方法については、「[ショップ管理](/admin/help/shops)」を参照してください。

## 1. データダンプ機能の概要

各エンティティのID（ユーザーID、ショップIDなど）を指定して、データベースに保存されている情報をJSON形式で取得します。
- **GSI 2対応**: `PRODUCT#` や `CARD_ORDER#` など、特定のインデックス（GSI 2）を介した検索が必要なデータにも対応しています。

## 2. 検索可能なデータ種別

ツール画面には、以下の種別ごとの検索ウィンドウが用意されています。

- **ユーザーID (USER#)**: アカウントの詳細情報。
- **ショップID (SHOP#)**: ショップの基本設定。
- **商品ID (PRODUCT#)**: ショップに紐づく商品データ（GSI 2経由）。
- **QR (QR#)**: 個別のカードデータ。
- **Card Order (CARD_ORDER#)**: 発注データの詳細（GSI 2経由）。
- **QR Batch (QR_BATCH#)**: カード発行時の設定(発注データ)のID、同時に発行したカード一覧。
- **カードデザイン (CARD_DESIGN#)**: 作成・登録されたデザイン定義。

## 3. 操作手順

1.  **IDの入力**: 検索したいデータのID（数字部分など）を入力します。プレフィックス（`USER#`等）は自動的に付与されます。
2.  **実行**: 「実行」ボタン（虫眼鏡アイコン）をクリックします。
3.  **クリア**: ゴミ箱アイコンを押すと、入力内容と検索結果がリセットされます。
