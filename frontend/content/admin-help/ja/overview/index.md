# システム管理者用ドキュメント

このセクションは管理者専用のヘルプページです。システムの管理方法や各機能の詳細について説明します。

## 管理ボタンの構成

管理者ダッシュボードには以下の主要なセクションがあります。

- **QRコード管理**: QRコードのバッチ生成、PDFダウンロード、およびステータスの確認（BAN処理を含む）が行えます。
- **カードデザイン編集**: ユーザーが使用するカードのデザイン（表・裏の色、フォント、背景画像など）を管理します。
- **ショップ・オーナー管理**: ショップの新規作成、オーナーの変更、マネージャーの紐付けなどを行います。
- **データ管理ツール**: システム内の各種データのダンプ（バックアップ用）を取得できます。

## QRコードの生成手順

1. **枚数の指定**: 生成したいQRコードの枚数を入力します。
2. **メタデータの付与**: 必要に応じて、特定のショップIDや有効期限、自動有効化フラグを設定できます。
3. **カードデザインの選択**: 生成するQRコードに使用するデフォルトのデザインを選択します。
4. **生成の実行**: 「生成」ボタンを押すと、サーバー側でユニークなUUIDとPINが発行され、自動的にPDFがダウンロードされます。

> [!IMPORTANT]
> 生成されたPDFは再発行ができません（セキュリティ上の理由）。ダウンロードしたPDFは大切に保管してください。

## セキュリティについて

管理画面のすべての操作は記録されており、**管理者（Administrators / GlobalAdmins）**権限を持つユーザーのみがアクセス可能です。また、多要素認証（MFA）が必須となっています。
