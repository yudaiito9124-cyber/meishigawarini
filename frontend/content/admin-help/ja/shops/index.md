# ショップ管理

[管理者ダッシュボード](/admin) の「ショップ管理」タブにおける、提携ショップの開設、オーナーの紐付け、およびデザインの利用制限などの管理操作について説明します。

## 各種IDの確認方法

管理操作を行う上で必要となるユーザーIDやショップIDは、以下の方法で確認できます。

### 1. ユーザーIDの確認
- **ユーザー自身に確認してもらう**: [マイページ](/user) の上部（メールアドレスやマイページ表示の下）にある英数字の文字列を確認してもらいます。
- **ショップ設定から確認**: [ショップ管理画面](/shop) の設定（歯車アイコン）下部に表示される「ユーザーID（ログイン中）」から確認できます。

### 2. ショップIDの確認
- **ショップ管理画面から確認**: ショップ管理画面の店名の下、またはURLの末尾（`/shop/...`）に表示されている英数字の文字列です。
- **カード一覧から確認**: カード一覧から該当カードの詳細を開き、ショップ情報を確認します。

## 1. ショップの新規作成

新しく「名刺代わりに」を導入するショップを作成します。
1. **ユーザーIDの指定**: ショップオーナーとなる方のユーザーID（英数字の文字列）を入力します。
2. **作成の実行**: 「ユーザーを確認」を押して内容を確認後、ショップを作成します。
※ショップ名などの詳細は、作成後にショップ管理者が自身の管理画面からいつでも変更可能です。

![ショップの新規作成](/images/manual/admin++TAB=shops+SECTION=shop_creation.webp)

## 2. ショップとカードデザインの紐付け管理

ショップごとに、使用できるカードデザインを制限・設定します。
1. **ショップの読み込み**: 対象のショップIDを入力して「読み込み」をクリックします。
2. **デザインの選択**: システム共通デザインやカスタムデザインの中から、そのショップでの利用を許可するデザインにチェックを入れます。
3. **保存**: 「保存」をクリックすると、対象ショップが発注できるカードデザインが更新されます。

![利用可能デザインの制限](/images/manual/p-ショップ管理-利用可能デザインの制限.png)

## 3. ショップオーナーの変更

既に存在するショップのオーナー権限を別のユーザーに移譲します。
1. **IDの指定**: 対象のショップIDと、新しいオーナーのユーザーIDを入力します。
2. **確認と実行**: 「変更内容を確認」で現在のオーナーと新しいオーナーの情報を確認し、問題なければ実行します。

![ショップオーナーの変更](/images/manual/admin++TAB=shops+SECTION=owner_change.webp)

## 4. ショップ管理者の紐づけ・解除

複数のスタッフ（マネージャー）を、複数のショップに対して一括で紐付け・解除します。
- 大規模な運用や、共通のスタッフが複数店舗を管理する場合に使用します。
- **複数IDの改行区切り入力**: 複数のショップと複数のユーザーを一度に紐付ける場合、それぞれのIDを改行（Enter）で区切って入力欄に入力します。

![ショップ管理者の紐づけ](/images/manual/p-マネージャーのバルク紐付け.png)
