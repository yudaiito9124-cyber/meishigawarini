# ショップ管理

システムの提携ショップの開設、オーナーの紐付け、およびデザインの利用制限などの管理操作について説明します。
![ショップ管理](/images/manual/admin++TAB=shops.webp)

##### IDの確認方法については、「[各種IDの確認方法](/admin/help/whereisid)」を参照してください。

## 1. ショップの新規開設

新しく「名刺代わりに」を導入するショップを作成します。
1.  **ユーザーIDの確認**: ショップオーナーとなる方のユーザーID（USER#...）を入力します。
2.  **作成**: 「実行」ボタンを押すと、そのユーザーをオーナーとしたデフォルトのショップが作成されます。
※ショップ名などの詳細は、作成後にショップ管理者が自身の管理画面から変更可能です。
![ショップ新規開設](/images/manual/admin++TAB=shops+SECTION=shop_creation.webp)

## 2. オーナーの変更

既に存在するショップのオーナー権限を別のユーザーに移譲します。
1.  **IDの指定**: 対象のショップIDと、新しいオーナーのユーザーIDを入力します。
2.  **確認と実行**: 「チェック」ボタンで現在のオーナーと新しいオーナーのメールアドレスを確認し、問題なければ「実行」します。

![オーナー変更](/images/manual/admin++TAB=shops+SECTION=owner_change.webp)

## 3. マネージャーのバルク紐付け

複数のスタッフ（マネージャー）を、複数のショップに対して一括で紐付けます。
- 大規模な運用や、共通のスタッフが複数の店舗を管理する場合に使用します。
- ユーザーIDとショップIDを改行区切りで入力し、全ての組み合わせで管理者権限を付与します。

![マネージャー紐付け](/images/manual/admin++TAB=shops+SECTION=manager_link.webp)

## 4. 利用可能デザインの制限

ショップごとに、使用できるカードデザインを制限（紐付け）します。
1.  **ショップの読み込み**: ショップIDを入力して読み込みます。
2.  **デザインの選択**: システム共通デザイン、またはカスタムデザインの中から、そのショップでの利用を許可するものにチェックを入れます。
3.  **保存**: 「保存」すると、対象ショップが発注できるカードのデザインが更新されます。なお過去に登録した商品に紐づいているカードデザインは、紐付けを解除しても発注可能です。

![利用可能デザインの制限](/images/manual/admin++TAB=shops+SECTION=design_link.webp)
