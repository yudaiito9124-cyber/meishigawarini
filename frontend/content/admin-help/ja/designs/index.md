# システム管理者マニュアル（デザイン設定）

カードの見た目（背景画像やQRコードの配置）を定義する「カードデザイン」の管理方法について説明します。

## 1. デザイン一覧

登録済みのデザインがタイル形式で表示されます。
- **新規作成**: 「New Design」ボタンから新しいデザインを追加します。
- **編集**: 各デザインの「ペン」アイコン（Paintbrush）をクリックして、エディタを開きます。
- **削除**: ゴミ箱アイコンから削除できます。

## 2. デザインエディタの使い方

エディタでは、プレビューを見ながらリアルタイムに配置を調整できます。

### 1 基本情報と画像
*   **Name / Description**: 管理しやすい名称と説明を入力します。
*   **Width / Height**: カードの物理サイズ（mm）を指定します。
*   **Background Images**: 表（Front）と裏（Back）の背景画像をアップロードします。

### 2 要素の配置調整
QRコード、PINコード、Code IDの3つの要素について、以下の設定が可能です。

*   **Front/Back切り替え**: 各要素の「Front」スイッチを切り替えることで、表裏どちらに配置するかを選択します。
*   **位置調整 (X, Y)**: 方向ボタンをクリックして、各要素の座標を微調整します。
*   **サイズ調整 (Size)**: 要素の大きさを調整します。

### 3 リアルタイムプレビュー
画面右側（または下部）に、現在の設定に基づいた表・裏の完成イメージが表示されます。背景画像に対してQRコード等がどのように重なるかをミリ単位で確認しながら調整してください。

## 3. 保存と運用への反映

「Save Design」をクリックすると保存されます。
保存したデザインは、ショップが「カード発注」を行う際の選択肢として現れたり、管理者が手動生成ツールを使用する際に指定できるようになります。
