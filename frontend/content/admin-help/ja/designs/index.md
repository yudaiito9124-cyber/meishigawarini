# デザイン設定

[管理者ダッシュボード](/admin) の「デザイン設定」タブにおける、カードの見た目（背景画像やQRコードの配置）を定義する「カードデザイン」の管理方法について説明します。
![デザイン一覧](/images/manual/admin++TAB=designs.webp)

## 1. デザイン一覧

登録済みのデザインがタイル形式で表示されます。
- **新規作成**: 「New Design」ボタンから新しいデザインを追加します。
- **編集**: 各デザインの「ペン」アイコン（Paintbrush）をクリックして、エディタを開きます。
- **削除**: ゴミ箱アイコンから削除できます。削除したデザインは復元できません。

## 2. デザインエディタの使い方

![デザインエディタ](/images/manual/p-デザインエディタの使い方.png)

エディタでは、プレビューを見ながらリアルタイムに配置を調整できます。

### 1 基本情報と画像
*   **Name / Description**: 管理しやすい名称と説明を入力します。
*   **Width / Height**: カードの物理サイズ（mm）を指定します。
*   **Background Images**: 表（Front）と裏（Back）の背景画像をアップロードします。300ppi(300pixel/25.4mm)以上の解像度を推奨するため、名刺・カードサイズ(91mm×55mm程度)であれば1100pixel×700pixel程度以上を推奨します。画像の形式は，png, jpeg, webpです。また、サムネイル画像(最大長辺1280px，縦横比元画像準拠、webp85%品質)が生成され、カード印刷以外の場面ではサムネイル画像が優先して表示されます。画像はカードのサイズに合うように縦横に引き伸ばされます。

### 2 要素の配置調整
QRコード、PINコード、Code ID(QRコードを読み込めない際に手打ちして検索するためのコードの一部)の3つの要素について、以下の設定が可能です。常に3つの要素はデザインに含めてください。

*   **Front/Back切り替え**: 各要素の「Front」スイッチを切り替えることで、表裏どちらに配置するかを選択します。
*   **位置調整 (X, Y)**: 方向ボタンをクリックして、各要素の座標を微調整します。
*   **サイズ調整 (Size)**: 要素の大きさを調整します。(QRコードは印刷時に読み込めること、PINコードは視認性が高いことを確認してください。)

### 3 リアルタイムプレビュー
画面右側（または下部）に、現在の設定に基づいた表・裏の完成イメージが表示されます。背景画像に対してQRコード等がどのように重なるかをミリ単位で確認しながら調整してください。

## 3. 保存と運用への反映

「Save Design」をクリックすると保存されます。
保存したデザインは、ショップが「カード発注」を行う際の選択肢として現れたり、管理者が手動生成ツールを使用する際に指定できるようになります。
