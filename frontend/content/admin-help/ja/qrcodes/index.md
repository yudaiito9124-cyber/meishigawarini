# システム管理者マニュアル（カード一覧）

システム内に存在するすべてのQRコードの状態確認や、個別カードの検索、不適切なカードの利用停止（BAN処理）を行う方法について説明します。

## 1. カードの検索

「カード一覧」タブを開くと、すべてのカードが一覧で表示されます。
- **キーワード検索**: カードID、管理者メモ、または紐付けられているメールアドレスなどで検索が可能です。入力すると自動的にリストがフィルタリングされます。
- **詳細の確認**: 各行をクリックすると、そのカードのメタデータ（ショップID、商品ID、作成日時、現在のステータスなど）の詳細が表示されます。

## 2. 利用停止（BAN処理）

不正な利用が発覚した場合や、紛失届があった場合に、そのカードを無効化します。
1.  **詳細を開く**: 対象カードをクリックして詳細ダイアログを表示します。
2.  **利用停止の実行**: 「利用停止 (BAN)」ボタンを押します。
3.  **理由の入力**: 停止理由（メモ）を入力し、確認ダイアログで「実行」を選択します。
停止されたカードは、ユーザーがQRコードを読み取っても交換画面が表示されなくなります。

## 3. 利用停止の解除（Restore）

利用停止したカードを再度有効に戻します。
- 詳細画面を開き、「利用停止を解除」ボタンをクリックします。確認後、ステータスが元の状態（通常は `SHIPPED` など）に戻ります。

## 4. BAN済みカードの完全削除

利用停止状態のまま、システムからエントリーを非表示（論理削除に近い処理）にしたい場合に使用します。
- ステータスが `BANNED` のカード詳細画面に表示される「削除」ボタンから実行します。
