# カード一覧

[管理者ダッシュボード](/admin) の「カード一覧」タブにおける、システム内に存在するすべてのQRコードの状態確認や、個別カードの検索、不適切なカードの利用停止（BAN処理）を行う方法について説明します。

## 1. カードの検索

「カード一覧」タブを開くと、すべてのカードが一覧で表示されます。
- **ID検索**: カードIDで検索が可能です。入力すると自動的にフィルタリングされます。
- **詳細の確認**: 各行をクリックすると、そのカードのメタデータ（ショップID、商品ID、作成日時、現在のステータスなど）の詳細が表示されます。

![カード検索](/images/manual/p-カード一覧-カード検索.png)

## 2. カード・注文の状態一覧（ステータスガイド）

カードや注文がどの状態にあるかを表すステータスの一覧です。

| ステータス | 意味・説明 |
| :--- | :--- |
| **未連携 (unassigned)** | カードが印刷されましたが、まだショップや商品と紐付けられていません。 |
| **連携済み (linked)** | ショップや商品と紐付けられましたが、まだ使用できるように有効化されていません。 |
| **有効化済み (active)** | 有効化されており、ギフトとして贈ることができる状態です。 |
| **発送待ち (used)** | 受取人が住所を入力し、発送待ちの状態です（ショップ側での発送作業待ち）。 |
| **発送済み (shipped)** | ショップが商品を発送し、追跡番号が登録された状態です。 |
| **受取り完了 (completed)** | 取引が正常に完了しました（受取人が受取完了報告を行った状態）。 |
| **期限切れ (expired)** | 使用期限が切れ、ギフトが無効になった状態です。 |
| **BAN済み (banned)** | 不正利用や紛失届などにより、システム管理者が利用停止させた状態です。 |
| **プロモーション (promotion)** | プロモーション用で、閲覧のみ可能なカードです。 |

## 3. 利用停止（BAN処理）

不正な利用が発覚した場合や、紛失届があった場合に、そのカードを無効化します。
1. **詳細を開く**: 対象カードをクリックして詳細ダイアログを表示します。
2. **利用停止の実行**: 「利用停止 (BAN)」ボタンを押します。
3. **理由の入力**: 停止理由（メモ）を入力し、確認ダイアログで「実行」を選択します。
停止されたカードは、ユーザーがQRコードを読み取っても交換画面が表示されなくなります。

## 4. 利用停止の解除（Restore）

利用停止したカードを再度有効に戻します。
- 詳細画面を開き、「利用停止を解除」ボタンをクリックします。確認後、ステータスが元の状態に戻ります。

## 5. BAN済みカードの完全削除

利用停止状態のまま、システムからエントリーを完全削除したい場合に使用します。
- ステータスが `BANNED` のカード詳細画面に表示される「削除」ボタンから実行します。二度と復旧できなくなります。
