# カード印刷

[管理者ダッシュボード](/admin) の「カード印刷」タブにおける、ショップからの発行依頼（注文）の管理と、管理者による新規カードの生成・印刷用データの書き出しについて説明します。

## 1. カード注文の処理フロー

提携ショップが [ショップ管理画面](/shop) の「カード発注」からカードの発注を行った場合、ここに「ORDERED（発注済み）」として表示されます。

1. **データの準備**: 対象の注文の「受託してカードを生成する」ボタンをクリックします。
2. **QRコードの自動生成**: 押下タイミングでシステムが自動的にUUIDとPINコードを枚数分発行し、ショップに紐付けます。
3. **ダウンロード**: 生成された印刷用データがブラウザからダウンロードされます。ダウンロードする際のPDFファイルの書式は、カード印刷タブ内一番上のConfig内から選択できます。

![カード注文の処理フロー](/images/manual/p-カード注文の処理フロー.png)

## 2. 管理者による手動生成（ツール）

プロモーション用や、管理者が直接カードを作成したい場合に使用します。手動生成を行うには、「手動生成セクションを表示」ボタンをクリックしてフォームを展開します。

1. **枚数の指定**: 一度に最大100枚まで生成可能です。
2. **デザインと用紙の選択**: カードのデザイン（Card Format）と、印刷する用紙のレイアウト（Paper Format）を選択します。画面上のプレビューでデザインを確認できます。
3. **詳細設定（オプション）**:
    * **ショップID / 商品ID**: 特定のショップや商品専用のカードとして発行したい場合に指定します。
    * **有効期限**: カードの利用期限を日付で直接設定できます。
    * **即時有効化**: ショップIDと商品IDを指定した場合のみ有効にできます。チェックを入れると、生成された瞬間にそのカードが使用可能な状態になります。有効期限は、有効期限で設定した日付、それが設定されていない場合は、生成時の日時にその商品の有効期間の日付を加えた日時になります。
4. **生成とダウンロード**: 「生成」ボタンを押すと、カードの注文（CARD_ORDER）が作成され、同時にPDFがダウンロードされます。

![管理者による手動生成](/images/manual/p-カード印刷-手動生成セクションを表示.png)

#### バッチ管理（生成履歴）

ページ下部には、手動生成でこのセクションを開いている間に生成（ダウンロード）したバッチの履歴が表示されます。
- **再ダウンロード**: 過去に生成したバッチのPDFやCSVを再度取得できます。
- **IDの確認**: 生成された個々のQR IDやPINコードを一覧で確認・コピーできます。
