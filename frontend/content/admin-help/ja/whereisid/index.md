# 各種IDの確認方法

システム管理を行うえで、ユーザーのIDやショップのIDなどを確認する方法について記載します。

## 1. ユーザーIDの確認方法

### ユーザー自身に確認してもらう
- ユーザーページ(/user)の「ユーザーページ」の文字列の下に表示

### ショップ管理者画面から確認してもらう(ショップを開設している場合)
- ショップ管理画面のショップの設定画面下部に表示される「ユーザーID(ログイン中)」(「ユーザーID(ショップオーナー)」とは異なるため注意)


## 2. ショップIDの確認方法


### ショップ管理者自身に確認してもらう
- ショップ管理画面のショップ名の下に表示
- ショップ管理画面のURL(shop/の後ろに続く文字列)

### システム管理画面から確認する
- そのショップが管理しているカードをカード一覧タブのリストから見つけ、カードの詳細画面のショップ情報から確認する

## 3. ツール画面から確認する
- システム開発者用Githubのdocuments/REF_DB_SCHEMA.mdに記載のデータベース構造を確認し、手持ちの種類のIDから探している種類のIDが紐づいているか確認。ツール画面のIDに基づいた検索を実施して生データから見つけ出す。
