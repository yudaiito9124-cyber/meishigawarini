# マイページの使い方

アカウントを作成してログインすることで、ギフトの履歴管理やプロフィールの設定などが可能になります。ここでは「**[マイページ](/user)**」の各機能について説明します。

## 概要

マイページでは、以下の操作を行うことができます。
- **[あなたのプロフィール](/user/editprofile)**: 贈り主として表示される名刺情報の編集
- **[ギフトを贈る前に](/user/sendgift)**: カードをご自身のプロフィールと紐付ける（贈り主の登録）
- **[贈ったギフト](/user/sentmemory) / [受け取ったギフト](/user/receivedmemory)**: 過去のやり取りの履歴確認
- **[いつもの受け取り住所](/user/editdelivery)**: ギフトを受け取る際の住所の自動入力設定

## 1. プロフィールの設定

### [あなたのプロフィール](/user/editprofile)
ご自身が贈り主となった際、相手（受取人）に表示されるプロフィール情報（名刺情報）を作成・編集します。
- 名前、会社名、役職、SNSリンク、顔写真などを設定できます。
- 「保存する」ボタンを押すと更新されます。

![プロフィール編集画面](/images/manual/user_profile_edit.webp)

## 2. ギフトの履歴管理

### [贈ったギフト](/user/sentmemory)
これまでにあなたが贈り主として紐付けたカードの一覧を確認できます。
- 相手がいつ住所を入力したか、発送が完了したかなどの状況をリアルタイムで把握できます。

### [受け取ったギフト](/user/receivedmemory)
あなたが受け取ったギフトの履歴を確認できます。
- カードを紛失してしまった場合でも、ここから配送状況の確認や、贈り主とのチャットを再開することができます。

![履歴一覧画面](/images/manual/user_history_list.webp)

## 3. 効率的なギフト受け取り

### [いつもの受け取り住所](/user/editdelivery)
ご自身の住所、氏名、電話番号などをあらかじめ登録しておくことができます。
- 新しくギフトを受け取る際、登録した情報が自動的に入力されるため、スムーズに手続きが完了します。

![配送先設定画面](/images/manual/user_delivery_settings.webp)

## 4. ショップの開設
「ショップを開設する」ボタンから、ご自身でギフトを販売・提供するためのショップを作成することができます。
※ショップの運営には、別途[ショップ管理画面](/help/shop)での設定が必要です。
