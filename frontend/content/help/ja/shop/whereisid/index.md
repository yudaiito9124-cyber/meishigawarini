# 各種IDの確認方法

[ショップ管理画面](/shop) や [マイページ](/user) において、スタッフの追加やシステム管理者への問い合わせ、各種設定を行う際に必要となるIDの確認方法について解説します。

## 1. ユーザーIDの確認方法

### あなた自身のユーザーIDを確認する場合
- **マイページから確認**: マイページの上部、メールアドレスやタイトルの下に表示される英数字の文字列です。
- **ショップ設定から確認**: ショップ管理画面の右上にある⚙（設定）アイコンを押し、設定画面の一番下に表示される「ユーザーID（ログイン中）」から確認できます。

### スタッフや共同管理者のユーザーIDを確認する場合
- 対象のスタッフに自身のマイページを開いてもらい、上部に表示されている英数字の文字列を教えてもらってください。

## 2. ショップIDの確認方法

### ショップ管理画面から確認する
- ショップ管理画面の左上、店名の下に表示されている英数字の文字列です。

### ブラウザのURLから確認する
- ショップ管理画面を開いている際、ブラウザのアドレスバーに表示されているURLの末尾（`/shop/` に続く英数字の文字列）がショップIDです。

## 3. 各種IDが必要になる主な場面

- **システム管理者への問い合わせ**: カードの不具合やデータ調査を依頼する際、ショップIDをお伝えいただくことで迅速な対応が可能になります。
- **スタッフ（管理者）の追加**: 複数人でショップを管理したい場合、追加したい方のユーザーIDをシステム管理者に伝えることで紐付け作業を行ってもらえます。
